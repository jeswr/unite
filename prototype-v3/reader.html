Read a Unite export

A second, read-only view that builds the whole record from an exported file alone: the proposal, every concern, the evidence, who decided under what authority, and the delivery trail.

The reader shares code with the demo, so it shows that the record travels with the file. It is not an independent implementation. The file is checked before anything is shown, and its text is displayed as plain text, never run.

It opens version 2 files (the “Learning opportunities for everyone” example, in US dollars). Version 1 files from the earlier example are refused, not relabelled or converted.
